# riff v1.0.0 — 질문이 캔버스를 채운다

riff v1.0은 모호한 제품 아이디어를 질문으로 구체화하고, 한 문서에서 다시 시작할 수
있게 만드는 Question-Driven 개발 루프의 전면 개편입니다.

## 주요 변경

- ASK→EXPLORE→BUILD→VERIFY→LEARN을 **FRAME→SHAPE→BUILD→PROVE→LEARN**으로 재구성
- `_workspace/CANVAS.md`를 현재 상태와 결정의 단일 SSOT로 도입
- 8개 신호에 따른 단순·보통·복잡 adaptive depth와 실패 시 소급 에스컬레이션
- 5개 skill을 progressive disclosure 기반 단일 `riff` skill로 통합
- worktree 병렬 탐색을 **Jam**, 안전한 랜딩을 **DROP**, 주기적 정리를 **TUNE**으로 정의
- Tier 0~3 proof, canvas-lint, cycle별 diff review, red-green 항체 검증
- `cycle-N:` 커밋 앵커와 증거 선보존 rewind protocol
- ralph-loop, Codex, ECC plan-canvas companion와 완전한 인라인 fallback

## 이번 릴리스 완성 작업

- Codex용 `.codex-plugin/plugin.json`과 로컬 marketplace 지원
- Claude Code용 hook을 선택적 SessionStart CANVAS 복원 하나로 최소화
- medium cycle 오버헤드 ≤15%를 판정하는 speed-tax runner
- 모호한 brief의 depth 반복 일관성 자동 채점
- macOS Bash 3.2 benchmark 호환과 fixture-ground-truth 매핑 복구
- 한국어·영문 README 제공

## 설치

Claude Code:

```text
/plugin marketplace add joyuno/riff
/plugin install riff@joyuno-riff
```

Codex 로컬 소스:

```bash
codex plugin marketplace add .
codex plugin add riff@joyuno-riff-local
```

설치 후 새 대화에서 `riff를 사용해 새 프로젝트를 시작해`라고 요청하세요.

- Claude/Codex plugin manifest 검증
