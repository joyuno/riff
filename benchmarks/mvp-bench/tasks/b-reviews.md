# B — 고객 리뷰 인사이트

## 첫 요청

> 쇼핑몰 고객 리뷰에서 지금 먼저 고쳐야 할 문제를 찾는 간단한 앱을 만들고 싶어요.

## 참가자 답변 카드

에이전트가 관련 내용을 물었을 때만 다음 사실로 답한다.

- 제공된 예시 리뷰만 사용하며 직접 입력·수집 기능은 필요 없다.
- 긍정·부정과 배송·포장·품질·사이즈 같은 주제를 보고 싶다.
- 주제와 감정으로 리뷰를 좁혀 원문을 확인하고 싶다.
- 리뷰마다 처리 전·검토 중·개선 반영 상태를 바꾸고 싶다.
- 처리 상태는 새로고침 후에도 남아야 한다.
- 외부 유료 AI나 API 키는 사용하지 않는다.
