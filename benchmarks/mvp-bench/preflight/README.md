# Synthetic Founder Preflight

세 Codex 서브에이전트가 업종 지식은 있지만 AI·개발 경험은 없는 창업자처럼
`riff:riff`를 사용해 MVP를 만드는 예비 실험이다.

이 결과는 실제 사용자 증거가 아니며 공식 MVP Bench 비교표에 합산하지 않는다.

```text
Execution: AI founder personas
Grading: maintainer-operated acceptance checks
Study: maintainer-operated, not independent
```

개별 실행자의 이름, 계정, 로컬 경로와 컴퓨터 정보는 공개하지 않는다.

## 실행

| Run | Persona | Product |
|---|---|---|
| `a-salon` | 미용실 운영자 | 예약·노쇼 관리 SaaS |
| `b-reviews` | 쇼핑몰 운영자 | 고객 리뷰 인사이트 도구 |
| `c-quotes` | 프리랜서 | 견적·고객 진행 관리 SaaS |

각 실행은 `runs/<run>/`만 수정한다. `acceptance/`는 실행 에이전트에게 제공하지 않는다.

잠정 결과는 [RESULTS.md](RESULTS.md)에 있다. 브라우저 검증 전 결과이며 공식 비교표에는
포함하지 않는다.
