## Discovery Research — 첫 추가 질문 3개

1. **[기록·계산] 항목별 견적이 필요한가요?**  
   실제 견적 도구는 보통 서비스 설명·수량·단가·할인·세금으로 합계를 계산합니다. 이를 포함하면 정확성과 설명력은 높아지지만 입력 화면이 복잡해집니다. 이번 MVP에 항목별 계산이 **필요 / 총액만으로 제외 / 잘 모르겠음** 중 무엇인가요? ([Zoho Invoice 도움말](https://www.zoho.com/en-sg/invoice/help/estimate/new-estimate.html))

2. **[상태·실수] 승인 상태와 변경 규칙을 어디까지 구분해야 하나요?**  
   표준 흐름은 초안→발송→승인·거절이며, 만료된 견적은 더 이상 승인할 수 없도록 제한하기도 합니다. **조회됨·변경 요청·만료와 승인 후 수정 제한까지 필요 / 기본 상태만 두고 제외 / 잘 모르겠음** 중 무엇인가요? ([Monite 견적 수명주기](https://docs.monite.com/accounts-receivable/quotes/index))

3. **[전달] 고객에게 견적을 어떻게 전달하고 승인을 받아야 하나요?**  
   실제 도구는 이메일, 웹 링크, PDF를 함께 제공하지만 자동 발송과 고객 직접 승인은 범위가 크게 늘어납니다. 앱 안에서 **링크·PDF 전달과 고객 직접 승인까지 필요 / 외부로 전달한 뒤 상태만 수동 기록 / 잘 모르겠음** 중 무엇인가요? ([HubSpot 견적 도움말](https://knowledge.hubspot.com/quotes/create-and-send-quotes))
