# B — 고객 리뷰 인사이트

## 판정

**실패 — critical 2개 미충족.** 브라우저 검증 전 결과다.

| 구분 | 결과 | 근거 |
|---|---|---|
| 예시 리뷰 사용 | 통과 | 로컬 fixture 리뷰를 즉시 표시 |
| 감정·주제 표시 | 통과 | 긍정·부정과 배송·포장·품질·사이즈 주제 표시 |
| 주제·감정 필터 | 통과(코드) | 필터와 빈 결과 안내 구현, 단위 테스트 통과 |
| 처리 상태 변경 | **실패** | 처리 전·검토 중·개선 반영 상태 모델과 UI가 없음 |
| 리뷰 요약 | 통과 | 전체 수, 평점, 부정 주제 우선순위 표시 |
| 새로고침 후 상태 유지 | **실패** | 저장할 처리 상태 자체가 없고 영속 저장도 없음 |
| 빈 리뷰 입력 | 판정 제외 | 공개 과제는 fixture 사용이며 리뷰 입력 기능을 요구하지 않아 기준이 과제와 불일치 |
| 검색 결과 빈 상태 | 통과(코드) | 필터 결과 없음 안내 구현 |
| 390px 흐름 | 미검증 | 반응형 규칙은 있으나 브라우저 실행 미완료 |
| 조사→결정 | 통과 | 리뷰 분류·우선순위 근거가 감정/주제 필터와 다음 행동에 연결됨 |
| 외부 유료 API 불필요 | 통과 | 정적 fixture와 로컬 로직만 사용 |
| CANVAS 일치 | **실패** | 완료로 선언했지만 처리 상태·영속성이 없음 |

## 실행 증거

- `npm test`: 통과, 요약·필터·우선순위 3개 검사 통과
- `npm run build`: 통과
- 브라우저 acceptance: 실행 환경의 브라우저 연결 부재로 미검증

## 관찰

조사와 읽기 전용 인사이트 화면은 완성했지만, 리뷰를 실제 업무 상태로 넘기는 핵심
루프가 빠졌다. 또한 숨은 기준의 `빈 리뷰 입력`은 공개 과제에서 유도되지 않아 공식
grader에 그대로 사용하면 안 된다.
